SQLite is the most widely deployed database engine in the world, found in every smartphone, browser, and countless embedded systems. Unlike client-server databases, SQLite reads and writes directly to ordinary disk files. A complete SQL database — tables, indexes, triggers, and views — is contained in a single cross-platform file.

## What makes SQLite different

SQLite is not a client-server database. It is a library that you link directly into your application. There is no separate server process to install, configure, or maintain. The entire database lives in a single file on disk.

<CardGroup cols={3}>
  <Card title="Zero Configuration" icon="gear">
    No installation, no server, no setup. Drop the library into your project and start running SQL.
  </Card>
  <Card title="Single File" icon="file">
    The entire database is stored in one portable file that works across all operating systems.
  </Card>
  <Card title="ACID Transactions" icon="shield-check">
    Full atomicity, consistency, isolation, and durability — even across crashes and power failures.
  </Card>
  <Card title="Public Domain" icon="lock-open">
    SQLite source code is in the public domain. Use it freely in any project, commercial or otherwise.
  </Card>
  <Card title="Cross-Platform" icon="globe">
    Runs on Linux, macOS, Windows, iOS, Android, WebAssembly, and virtually every embedded platform.
  </Card>
  <Card title="Amalgamation" icon="cubes">
    Distribute as a single 200K-line C file. Easier to integrate than a multi-file library.
  </Card>
</CardGroup>

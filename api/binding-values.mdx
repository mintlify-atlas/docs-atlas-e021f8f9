Parameter binding is the secure and efficient way to pass values into a prepared statement. Instead of constructing SQL strings with embedded literals — a practice that invites SQL injection and forces type conversions — you place placeholders in your SQL text and then bind typed C values to them before calling `sqlite3_step()`. SQLite preserves the type information through the entire query plan, enabling proper index usage and avoiding unnecessary text conversions.

## Parameter Placeholders

SQLite recognizes five placeholder syntaxes in SQL text:

| Syntax | Example | Notes |
|--------|---------|-------|
| `?` | `WHERE id = ?` | Anonymous; index assigned left to right starting at 1 |
| `?NNN` | `WHERE id = ?1` | Explicit numeric index |
| `:name` | `WHERE id = :user_id` | Named parameter (colon prefix) |
| `@name` | `WHERE id = @user_id` | Named parameter (at-sign prefix) |
| `$name` | `WHERE id = $user_id` | Named parameter (dollar-sign prefix, Tcl convention) |

Named parameters with the same name share the same binding index, so binding one also sets all occurrences of that name in the statement.

<Note>
  All binding indices are **1-based**. The first `?` in a statement is index 1, the second is index 2, and so on. This is the opposite of column-reading indices, which are 0-based.
</Note>

## sqlite3_bind_* Functions

All binding functions share the same signature pattern and return `SQLITE_OK` on success, or an error code (e.g., `SQLITE_RANGE` if the index is out of bounds, `SQLITE_NOMEM` on allocation failure).

### Integer Bindings

```c
int sqlite3_bind_int(sqlite3_stmt *stmt, int col, int value);
int sqlite3_bind_int64(sqlite3_stmt *stmt, int col, sqlite3_int64 value);
```

<ParamField path="stmt" type="sqlite3_stmt *" required>
  The prepared statement to bind to.
</ParamField>
<ParamField path="col" type="int" required>
  1-based parameter index.
</ParamField>
<ParamField path="value" type="int / sqlite3_int64" required>
  The integer value to bind. Use `sqlite3_bind_int64()` for values outside the 32-bit range.
</ParamField>

```c
/* Bind a 32-bit int */
sqlite3_bind_int(stmt, 1, 42);

/* Bind a 64-bit int */
sqlite3_bind_int64(stmt, 2, 9007199254740993LL);
```

### Floating-Point Binding

```c
int sqlite3_bind_double(sqlite3_stmt *stmt, int col, double value);
```

```c
sqlite3_bind_double(stmt, 1, 3.14159265358979);
```

### Text Bindings

```c
int sqlite3_bind_text(sqlite3_stmt *stmt, int col,
                      const char *text, int nbytes,
                      void (*destructor)(void *));

int sqlite3_bind_text64(sqlite3_stmt *stmt, int col,
                        const char *text, sqlite3_uint64 nbytes,
                        void (*destructor)(void *),
                        unsigned char encoding);
```

<ParamField path="text" type="const char *" required>
  Pointer to the UTF-8 (or UTF-16 for `bind_text64`) text data.
</ParamField>
<ParamField path="nbytes" type="int" required>
  Length of the text in bytes. If negative, SQLite reads up to the first NUL terminator. For `bind_text64`, this is a `sqlite3_uint64`.
</ParamField>
<ParamField path="destructor" type="void (*)(void *)" required>
  Controls memory management. See [Destructor Constants](#destructor-constants) below.
</ParamField>
<ParamField path="encoding" type="unsigned char">
  For `bind_text64` only: `SQLITE_UTF8`, `SQLITE_UTF16`, `SQLITE_UTF16BE`, or `SQLITE_UTF16LE`.
</ParamField>

```c
/* Stack or static string — tell SQLite to copy it */
sqlite3_bind_text(stmt, 1, "hello", -1, SQLITE_TRANSIENT);

/* Heap string SQLite will free with sqlite3_free() — avoid double-free */
char *name = sqlite3_mprintf("user_%d", user_id);
sqlite3_bind_text(stmt, 2, name, -1, sqlite3_free);

/* String that outlives the statement — no copy needed */
static const char *LABEL = "active";
sqlite3_bind_text(stmt, 3, LABEL, -1, SQLITE_STATIC);
```

### BLOB Bindings

```c
int sqlite3_bind_blob(sqlite3_stmt *stmt, int col,
                      const void *data, int nbytes,
                      void (*destructor)(void *));

int sqlite3_bind_blob64(sqlite3_stmt *stmt, int col,
                        const void *data, sqlite3_uint64 nbytes,
                        void (*destructor)(void *));
```

Identical semantics to `bind_text`, but for binary data. The `nbytes` argument is never negative and must accurately reflect the size of the buffer.

```c
uint8_t image_data[1024];
/* ... fill image_data ... */

/* SQLite will copy the data (SQLITE_TRANSIENT) */
sqlite3_bind_blob(stmt, 1, image_data, sizeof(image_data), SQLITE_TRANSIENT);
```

Use `bind_blob64` when the data size may exceed 2 GiB.

### NULL Binding

```c
int sqlite3_bind_null(sqlite3_stmt *stmt, int col);
```

Binds SQL `NULL` to parameter `col`. All parameters default to `NULL` before any binding call, so this is mainly useful for explicitly resetting a parameter.

```c
sqlite3_bind_null(stmt, 3);
```

### sqlite3_value Binding

```c
int sqlite3_bind_value(sqlite3_stmt *stmt, int col, const sqlite3_value *value);
```

Binds a copy of an `sqlite3_value` object — the generic value type used internally and in application-defined functions. The source value must be a protected value (i.e., obtained from a function argument or `sqlite3_column_value()`).

```c
/* Typically used inside application-defined SQL functions */
sqlite3_bind_value(stmt, 1, argv[0]);
```

### Pointer Binding

```c
int sqlite3_bind_pointer(sqlite3_stmt *stmt, int col,
                         void *ptr, const char *type,
                         void (*destructor)(void *));
```

Binds a C pointer as a special `POINTER` type (not stored in the database). The `type` string is a static application-defined tag used to verify pointer types in custom functions. The pointer is passed through to SQL functions that call `sqlite3_value_pointer()` to retrieve it.

```c
MyContext *ctx = create_context();
sqlite3_bind_pointer(stmt, 1, ctx, "MyContext", free_context);
```

### Zero-Blob Bindings

```c
int sqlite3_bind_zeroblob(sqlite3_stmt *stmt, int col, int n);
int sqlite3_bind_zeroblob64(sqlite3_stmt *stmt, int col, sqlite3_uint64 n);
```

Bind a BLOB of `n` zero bytes without allocating a buffer. Useful for reserving space in a BLOB column that will later be written incrementally using the `sqlite3_blob_*` incremental BLOB I/O interface.

```c
/* Reserve 1 MB of zero bytes */
sqlite3_bind_zeroblob(stmt, 1, 1024 * 1024);
```

## Destructor Constants

The `destructor` parameter of text and BLOB binding functions controls the lifetime of the pointed-to data:

| Constant | Value | Meaning |
|----------|-------|---------|
| `SQLITE_STATIC` | `((sqlite3_destructor_type)0)` | The data is static or will outlive the statement. SQLite uses the pointer directly without copying and calls no destructor. |
| `SQLITE_TRANSIENT` | `((sqlite3_destructor_type)-1)` | SQLite immediately makes a private copy of the data. Safe to use with any buffer. Incurs a memory allocation. |
| Custom function pointer | Any `void(*)(void*)` | SQLite calls this function with the data pointer as its argument when the binding is replaced or the statement is finalized. Use this to hand ownership of a heap allocation to SQLite. |

<Tip>
  Use `SQLITE_STATIC` when binding string or BLOB constants, and `SQLITE_TRANSIENT` when binding values from stack buffers or local variables that will go out of scope before the statement executes. Use a custom destructor when passing heap-allocated data to transfer ownership.
</Tip>

## Parameter Introspection

### sqlite3_bind_parameter_count

```c
int sqlite3_bind_parameter_count(sqlite3_stmt *stmt);
```

Returns the index of the largest (rightmost) parameter. For statements using only `?` and `:name` forms, this equals the number of unique parameters. For `?NNN` forms with gaps (e.g., `?1` and `?3`), the count is the highest index (3), not the number of distinct parameters.

### sqlite3_bind_parameter_name

```c
const char *sqlite3_bind_parameter_name(sqlite3_stmt *stmt, int N);
```

Returns the name of the N-th parameter (1-based), including its leading `:`, `@`, `$`, or `?NNN` prefix. Returns `NULL` for anonymous `?` parameters or if N is out of range. The returned string is always UTF-8.

```c
int n = sqlite3_bind_parameter_count(stmt);
for (int i = 1; i <= n; i++) {
    const char *name = sqlite3_bind_parameter_name(stmt, i);
    printf("  param %d: %s\n", i, name ? name : "(anonymous)");
}
```

### sqlite3_bind_parameter_index

```c
int sqlite3_bind_parameter_index(sqlite3_stmt *stmt, const char *zName);
```

Returns the binding index for a named parameter. Returns `0` if no parameter with that name exists. The name must include the leading `:`, `@`, or `$` prefix.

```c
int idx = sqlite3_bind_parameter_index(stmt, ":user_id");
if (idx > 0) {
    sqlite3_bind_int64(stmt, idx, user_id);
}
```

## Clearing All Bindings

```c
int sqlite3_clear_bindings(sqlite3_stmt *stmt);
```

Resets all bound parameters back to SQL `NULL`. Note that `sqlite3_reset()` does **not** clear bindings — you must call this explicitly if you want a clean slate before re-executing.

```c
sqlite3_reset(stmt);          /* reset execution state */
sqlite3_clear_bindings(stmt); /* reset all params to NULL */
```

## Complete Examples

<Tabs>
  <Tab title="Integer & Text">
    ```c
    sqlite3_stmt *stmt;
    sqlite3_prepare_v2(db,
        "INSERT INTO users (id, name, age) VALUES (?1, ?2, ?3)",
        -1, &stmt, NULL);

    sqlite3_bind_int64(stmt, 1, 42);
    sqlite3_bind_text(stmt,  2, "Alice", -1, SQLITE_STATIC);
    sqlite3_bind_int  (stmt, 3, 30);

    int rc = sqlite3_step(stmt);
    if (rc != SQLITE_DONE) {
        fprintf(stderr, "Insert failed: %s\n", sqlite3_errmsg(db));
    }
    sqlite3_finalize(stmt);
    ```
  </Tab>
  <Tab title="BLOB">
    ```c
    sqlite3_stmt *stmt;
    sqlite3_prepare_v2(db,
        "INSERT INTO files (name, data) VALUES (:name, :data)",
        -1, &stmt, NULL);

    void *buf = malloc(file_size);
    /* ... fill buf with file data ... */

    sqlite3_bind_text(stmt,
        sqlite3_bind_parameter_index(stmt, ":name"),
        filename, -1, SQLITE_TRANSIENT);

    /* Transfer ownership of buf to SQLite */
    sqlite3_bind_blob(stmt,
        sqlite3_bind_parameter_index(stmt, ":data"),
        buf, (int)file_size, free);

    sqlite3_step(stmt);
    sqlite3_finalize(stmt);
    /* buf will be freed by SQLite via the 'free' destructor */
    ```
  </Tab>
  <Tab title="Reuse with Reset">
    ```c
    sqlite3_stmt *stmt;
    sqlite3_prepare_v2(db,
        "SELECT score FROM grades WHERE student_id = ?",
        -1, &stmt, NULL);

    int student_ids[] = {101, 102, 103};
    for (int i = 0; i < 3; i++) {
        sqlite3_bind_int(stmt, 1, student_ids[i]);

        if (sqlite3_step(stmt) == SQLITE_ROW) {
            printf("Student %d: score = %d\n",
                   student_ids[i],
                   sqlite3_column_int(stmt, 0));
        }

        sqlite3_reset(stmt);  /* bindings are preserved across reset */
    }

    sqlite3_finalize(stmt);
    ```
  </Tab>
  <Tab title="Double & NULL">

    ```c
        "INSERT INTO measurements (device, value, notes) "
        "VALUES (?, ?, ?)",
        -1, &stmt, NULL);

    sqlite3_bind_text  (stmt, 1, "sensor_01", -1, SQLITE_STATIC);
    sqlite3_bind_double(stmt, 2, 98.6);
    sqlite3_bind_null  (stmt, 3);  /* no notes */

    sqlite3_step(stmt);
    sqlite3_finalize(stmt);
    ```

## Quick Reference

| Function | Binds |
|----------|-------|
| `sqlite3_bind_int(stmt, col, val)` | 32-bit integer |
| `sqlite3_bind_int64(stmt, col, val)` | 64-bit integer |
| `sqlite3_bind_double(stmt, col, val)` | IEEE 754 double |
| `sqlite3_bind_text(stmt, col, text, n, destr)` | UTF-8 text |
| `sqlite3_bind_text64(stmt, col, text, n, destr, enc)` | Text with explicit encoding |
| `sqlite3_bind_blob(stmt, col, data, n, destr)` | Binary data |
| `sqlite3_bind_blob64(stmt, col, data, n, destr)` | Binary data (64-bit size) |
| `sqlite3_bind_null(stmt, col)` | SQL NULL |
| `sqlite3_bind_value(stmt, col, val)` | Copy of sqlite3_value |
| `sqlite3_bind_pointer(stmt, col, ptr, type, destr)` | Opaque pointer (pass-through) |
| `sqlite3_bind_zeroblob(stmt, col, n)` | N zero bytes (no buffer) |
| `sqlite3_bind_zeroblob64(stmt, col, n)` | N zero bytes (64-bit size) |
